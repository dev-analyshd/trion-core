# Deep Read: scripts/ + zg/ + deploy/ + config/ + .github/ + top-level

Agent 2-i · TRION Protocol repo deep-read (READ-ONLY) · ~112 files read (most fully; long test/report files skimmed structurally).

Repo context: git history spans **2026-05-13 → 2026-09-01** (single author, `dev-analyshd`). Sandbox clock also reads 2026. All "future-looking" dates below are internally consistent with that clock.

## Overview

The assigned surface is the **operational shell** of TRION: 36 orchestration/deploy scripts, the 0G integration daemons (zg/), 12 deploy manifests (docker/systemd/monitoring/nginx), 4 config files, 10 CI workflows + CODEOWNERS (no dependabot — it doesn't exist), and ~50 top-level files. Verdict up front:

- **Genuinely strong**: `schema.sql` (33-table TimescaleDB with append-only "thermodynamic" triggers), `Dockerfile.railway` + `railway-entrypoint.sh` (well-engineered single-container 4-process stack with preflight, watchdog, /readyz gating), `deploy_preflight.py`/`mainnet_preflight.py` (real go-live gates incl. a compromised-deployer blocklist), the internal `TRION_AUDIT_REPORT.md` (unusually honest), and `zg_sync_daemon.py`/`zg_da_streamer.py` (real daemons with SQLite fallbacks).
- **Broken as shipped**: `Makefile` (space-indented recipes — `make` fails with "missing separator" on every target), `scripts/genesis_backfill_runner.py` (reads `akashic/chains_registry_evm.json` which doesn't exist — crashes at import), `scripts/phase7_contract_verify.py` & `final_cross_check.py` & `run_whitepaper_tests.sh` (all reference pre-restructure `contracts/*.sol` paths that no longer exist), `deploy/docker/Dockerfile.{api,faiss}` (`COPY requirements.txt` — no root requirements.txt), `deploy/systemd/trion-validator.service` (runs `python3 -m validator.node` against a **Go** module), `scripts/deploy_and_activate.py` + `deploy_execution_gate_0g.mjs` (wrong contract source paths), `deploy_akashic_proof.mjs` (deploys from an artifact whose committed `bytecode` is the empty string `"0x"`).
- **Claims vs reality**: deployable mainnet story is thin — `deploy_mainnet.py` never deploys anything (prints a plan); "on-chain proof" scripts record placeholder/synthetic hashes on-chain; chain-count claims oscillate between 12/18/21/24/53/55/78/96/100+/124 across files; `AUDIT_RESOLUTION_REPORT.md` cites two scripts (`trim_pyproject_sources.py`, `fix_shim_underscores.py`) that are **not in the repo**; the task-listed evidence file `crossvm_zero_bridge_result.json` **does not exist** in the repo; every testnet deployment and the live relayer wallet is `0xdBbf66…d20` — the exact wallet `mainnet_preflight.py` flags as "compromised-history".

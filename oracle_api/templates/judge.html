Architecture

How TRION Works

Raw blockchain activity → 9 Shannon entropy features → 128-dim behavioral vector → FAISS archetype match → C(t) coherence score → 0G on-chain verdict → DeFi protocol gate.

STEP 1
L0 Rust Indexers
13 Rust crates index 35 networks in real time. For every block: extract 9 Shannon entropy features (volume, counterparty diversity, temporal spacing, gas patterns, MEV signatures). 93-byte canonical Behavioral Hash per transaction.
STEP 2
FAISS ANIMA Engine
9 features → 128 dimensions (interaction terms + temporal lags). k-NN search against 64 pre-trained attack archetypes. ANIMA score A = evolutionary fitness vs. nearest archetype. Thermodynamic entropy conservation law verified.
STEP 3
Five-Plane Scoring
C(t) = 0.25·Φ + 0.30·M + 0.25·Σ + 0.10·K + 0.10·A
Φ Physical · M Mental · Σ Spiritual · K Conscious · A ANIMA
Θ(t) = 0.55 + 0.37·volatility — dynamic manipulation threshold.
STEP 4
0G ExecutionGate
C(t) published to TRIONExecutionGate on 0G Mainnet every 60s. Any DeFi protocol integrates one Solidity call: checkExecution(address) → (bool allowed, string reason). Wallets with STATUS_HOSTILE are blocked on-chain.

How to Save as PDF

Use your browser's built-in print function to export a pixel-perfect PDF. No third-party tools needed. The print versions are specially formatted for clean output.

1

Open Print Version

Click "Open Print Version" on either card above. It opens in a new tab, formatted for printing.

2

Open Print Dialog

Press Ctrl+P (Windows/Linux) or Cmd+P (Mac) to open the browser print dialog.

3

Select "Save as PDF"

In the Destination/Printer dropdown, choose "Save as PDF" or "Microsoft Print to PDF".

4

Set Paper Size

Book: A4 Portrait. Pitch Deck: A4 Landscape (or custom 16:9). Save.

Ctrl+POpen Print (Windows)
Cmd+POpen Print (Mac)
DestinationChoose "Save as PDF"
More SettingsTurn on "Background graphics"

⚠️ Enable Background graphics in More Settings — required for the dark theme to appear correctly in the PDF.

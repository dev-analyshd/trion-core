## Why the v1 artifacts were degenerate

1. **Empty signal path** — v1 queried the live Oracle API for all 40 dataset
   entities; FAISS held no behavioral sediment for any of them, so every
   response was the typed `COLD_START/SILENCE` fallback with
   `coherence_score = 0.0` (visible in the v1 report: threshold 0.55 default,
   planes `{}`).
2. **Tautological detector** — `silence = not coherent` followed by
   `trion_flagged = not coherent or silence` collapses to
   `trion_flagged = not coherent`; with every coherence at 0.0 this is an
   unconditional flag: TP=30, FP=10, TN=0, FN=0, F1 85.71%, "$3.315B caught".
3. The README quoted only the flattering half of that artifact (DD §6.1).

## What v2 changes (evidence, not narrative)

- **Signal path:** `backtest/replay_engine.py` synthesizes deterministic,
  record-parameterized behavioral event histories (attacker replays from the
  public exploit record: burst timing, magnitude concentration, entropy
  collapse, counterparty concentration, replayed oracle price paths; control
  replays from organic protocol/wallet activity models) and scores them
  through the real `core/` pipeline:
  `core.thermodynamics.entropy_engine` → `core.physical.manipulation_detector`
  → `core.master.coherence` (five-plane master equation).
- **Detector logic:** `trion_flagged = C(t) < θ_calibrated`; `silence`
  (engine dynamic Θ(t) gate) is reported separately and never feeds the flag.
- **Threshold:** Youden's J (TPR − FPR) maximization over a 0.30–0.85 grid
  on the labeled replay cohort — method and grid disclosed in the report
  metadata. The held-out run calibrates on TRAIN only and freezes θ for TEST.
- **Honesty gates:** the flagship run exits non-zero if separation_delta
  ≤ 0.15, FPR > 0.3, TN < 7, precision < 0.85, or any plane payload is empty.
